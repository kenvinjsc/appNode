# Phím tắt

Gán lại được trong app (Xem → Phím tắt, hoặc `?`), lưu cho từng máy. Mặc định nằm trong `app/src/shared/shortcuts.ts`.

| Phím | Hành động |
|---|---|
| Delete | Xóa |
| Ctrl+D | Sao chép |
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | Hoàn tác / Làm lại |
| Q / M / R | Chọn / Di chuyển / Xoay |
| F / Shift+F | Phóng vừa vùng chọn / toàn bộ |
| 1 2 3 4 5 / 0 | Trước, Sau, Trái, Phải, Trên / Phối cảnh |
| H | Ẩn/hiện |
| F2 | Đổi tên |
| Shift+R / Shift+D | Quan hệ lắp ghép / Kích thước |
| Ctrl+A | Chọn tất cả |
| Ctrl+S / Ctrl+O | Lưu / Mở |
| Esc | Hủy công cụ → đóng menu → bỏ chọn |

Chuột trong khung 3D: kéo trái = xoay; kéo phải = pan; cuộn = zoom; Shift+kéo = quét chọn; Ctrl+click = thêm/bớt;
click vào chi tiết của tủ lần đầu chọn cả tủ, lần hai chọn chi tiết (Alt+click chọn thẳng chi tiết).
