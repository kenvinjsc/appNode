# 04. Giao diện (`app/`)

React 18 + TypeScript 5.6 + Vite 5, Three.js 0.169, zustand. Không thư viện UI; style ở `app/src/styles.css`.
Giao diện tiếng Việt, sáng, màu nhấn cam `#e8590c`, icon SVG trong `app/src/shared/icons.tsx` (không emoji).

## Thư mục

```
app/src/
  core-api/      transport.ts (IPC | fetch /api, hàng đợi tuần tự)
                 commands.ts  (Commands.*: lệnh sửa → phát events + báo lỗi tiếng Việt)
                 queries.ts   (Queries.*: chỉ đọc)
                 events.ts    (onCoreEvents / onHistoryStatus)
                 types.ts     (kiểu TS khớp JSON của core)
                 errors.ts    (mã lỗi → thông báo tiếng Việt)
  app/           App.tsx (bố cục), Chrome.tsx (menu chuột phải, hộp thoại, toast), Ribbon.tsx,
                 Shortcuts.tsx, actions.ts (hành động dùng chung menu / phím tắt), uiStore.ts (zustand)
  viewport/      Viewport.tsx, renderer/ViewportEngine.ts (scene Three.js, InstancedMesh, chọn),
                 renderer/geometryCache.ts, sceneSync.ts (sự kiện → cập nhật tăng dần),
                 materials/materials.ts, gizmo/, overlays/ (kích thước, handle W/H/D, quan hệ)

    drawing2d/     Drawing2D.tsx (view Trước / Sau / Trái / Phải / Trên / mặt cắt), EditLayer.tsx
                   (khoang, kéo vách / kệ / cạnh, số đo sửa được, BackZoneLayer), PrintSheet.tsx (D29)
    properties/    PropertiesPanel.tsx (bảng thuộc tính sinh từ core, MachineExport D26)
    scene-tree/    SceneTree.tsx, rooms.ts (tab tầng / phòng)

    manufacturing/ nesting/ cnc/ report/ materials/
```

## Luồng dữ liệu

1. Người dùng thao tác → gọi `Commands.xxx(...)` (không bao giờ tự sửa trạng thái mô hình phía UI).
2. `command()` gửi request; nhận `Response` → `emitStatus` (undo/redo) → `emitCoreEvents(events)`;
   lỗi → toast tiếng Việt qua `describeError` rồi ném `CommandError` (bắt bằng `.catch(() => undefined)` nếu chỉ cần toast).
3. Người nghe sự kiện:
   - `viewport/sceneSync.ts`: `ObjectCreated/Changed/GeometryChanged/TransformChanged` → `Queries.renderObjects(ids, knownKeys)`
     (core chỉ gửi mesh có `geometry_key` mới), `ObjectDeleted` → gỡ, `SceneTreeChanged` → tải lại cây,
     `ProjectLoaded` → tải lại hết.
   - `features/cabinet/useZones.ts`: `ZonesChanged {cabinets}` → tải lại khoang tủ đó (2D, Tạo tấm).
   - Bảng thuộc tính, báo cáo: tải lại theo `revision` trong `uiStore`.

## uiStore (`app/src/app/uiStore.ts`)

Một store zustand: `workspace`, `ribbonTab`, `selection`/`active`/`face`/`edge`, `tree`, `materials`, `toasts`, `jobs`,
`contextMenu`/`zoneMenu`, `pinned` (khoang ghim), hộp thoại đang mở (`structureOf`, `gallery`, `arrayOf`, `runOf`, `prompt`),
`activeRoom`, `canUndo/canRedo/revision`… Chỉ chứa **trạng thái giao diện** và bản sao chỉ đọc lấy từ core.

## Viewport

- `ViewportEngine.ts`: mỗi `RenderObject` (id, geometry_key, ma trận thế giới, material, `look?`) vào một
  `InstanceGroup` theo khóa `geometry_key|look`. Mesh dựng một lần trong `geometryCache` theo `geometry_key`.
- `materials.ts`: vật liệu theo mã vật liệu; `hardwareMaterial(look)` cho kính (trong suốt, `depthWrite=false`,
  `renderOrder=2`, không đổ bóng) và gương.
- Chọn mặt / cạnh dùng face id / edge id từ tessellation của core. Render theo yêu cầu (không vòng lặp liên tục).
- Gizmo di chuyển / xoay: xem trước cục bộ, thả chuột gửi `move_objects` / `set_parameter rx…`; snap hỏi core (`snap`).

## 2D (`features/drawing2d`)

- `Drawing2D.tsx`: chọn view (`front | back | side | right | top | section_x | section_y`), chiếu hộp tấm / khoang từ dữ liệu core
  (`get_zones`, `get_render_objects`), `project()` trong `EditLayer.tsx` đổi tọa độ tủ → mặt phẳng view (view sau lật X).
- `EditLayer.tsx`: lớp tương tác — `.d2e-zone` (ghim, chuột phải → Dựng nhanh), kéo vách / kệ (`preview` khi kéo,
  commit khi thả), số đo bấm để sửa (`set_bay`, `set_parameter`), kéo cạnh tấm (`resize_panel_side`). Khoang phụ kiện
  không vừa có lớp `.misfit`.

## Bảng sinh từ core

`StructureDialog`, tab sản phẩm, `PropertiesPanel` nhận danh sách field `{key, label, kind: number|bool|text|select|section,
value, options?, hint?}` và gọi `Commands.setParameter(id, key, value)`. Thêm tùy chọn mới ở core là UI tự hiện.
Chỉ viết component riêng khi cần tương tác đặc biệt (ví dụ `Cutouts` cho danh sách lỗ khoét hậu, `RoomTypeRow`).

## Quy ước UI

- Chữ hiển thị tiếng Việt ngắn gọn; nhãn trong core cũng tiếng Việt.
- Menu / popup dài phải `maxHeight` + `overflowY: 'auto'` và kẹp trong cửa sổ (đã làm ở `Chrome.tsx`).
- Tải file: tạo `<a download>` gắn vào DOM rồi click; tên file bỏ dấu (xem MachineExport).
- Nhập liệu dùng `uiStore.prompt`, báo lỗi / thành công dùng toast. `confirm()` gốc chỉ còn ở vài chỗ xóa (CabinetDesigner, ToolColumn); mã mới nên tránh.
